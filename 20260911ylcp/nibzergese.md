# 老年妇女做无卵试管，请看这里-老年无卵试管常见问题！

> 更新时间：2026-09-11 (UTC+8)

40岁以上的老年妇女自然怀孕的概率很低。即使通过常规试管婴儿帮助怀孕，成功率也低于20%。如果常规试管婴儿三次失败，医生会建议做无卵试管婴儿。老年妇女做无卵试管，请看这里。建议您在选择之前清楚了解以下老年妇女做无卵试管的相关问题。

**一、国内卵试管婴儿需要满足的条件**

1、身份证，结婚证

这是中国对进行甚至辅助技能的人的基本要求。无论我们想做什么样的试管婴儿，我们都需要准备三个证件：身份证、结婚证和出生证。如果我们缺少一个，我们就不能在中国做试管婴儿。也就是说，只要我们结婚并满足计划生育的要求，我们就可以要求在中国做试管婴儿（借）卵。

2、女方确实有无卵问题

因为卵试管婴儿是用第三方卵子受精的，只要女性朋友真的不能提供健康的卵子，就可以做卵试管婴儿，比如卵巢早衰、卵巢缺失、卵子质量差的女性朋友。如果想生孩子，可以选择卵试管婴儿计划。

3、男人没问题

一般来说，卵子试管受精夫妇要求男性没有健康问题，也就是说，男性可以提供健康和高质量的精子，否则如果男性不能提无精子，可能需要精子+卵子计划来解决问题，所以我们做（借）卵子试管受精来了解他们是否合适。

4、子宫状况良好

子宫是胚胎植入和发育的地方。如果女性朋友的子宫环境异常，如子宫内膜炎、子宫异位症等，会影响胚胎的植入和发育。在这种情况下，建议在**试管婴儿前进行相关治疗和调理。

 

**二、老年妇女做无卵试管流程**

1、第一个环节:夫妻双方体检

进食前，夫妻双方应进行全面的体检，以确保患者的身体状况适合(借)卵试管婴儿治疗。其中，妇女一般要做妇科检查、血常规、雌激素六项、阴道B超检查，前两种可以随时做，后两种可以在月经后2~3天做。男性主要做血常规和精液测试，禁欲3~7天后进行。一般来说，所有的体检项目都是在10天内完成的，但如果患者进行染色体检查，结果通常需要一个多月才能出来。因此，建议患者在体检前1~2个月进行体检。如果身体有任何影响**治疗的问题，也可以利用这段时间进行调理治疗。

2、第二个环节：配对**

受要求影响，国内公立医院基本处于**“零库存”状态，患者一般要等三五年才能有**。如果患者找私人机构，机构通常会根据患者的要求配对**，如年龄、学历、血型、身高等。这个过程一般需要1~2个月。

3、第三个环节:促排卵( 者)

受精卵配对后，在月经第二天的无卵日开始排卵10~12天。促排前的晚上，医生先给患者注射HCG，然后第二天早上促排( 者月经期13~14天)。另外，促排当天，男方也要去医院取精。

4、第四个环节：胚胎移植

将精子和卵子放入带有特殊培养液的培养皿中受精。胚胎培养可在3~6天内完成移植；如果患者的身体状况不能满足要求或需要染色体筛查和基因诊断，则需要冷冻胚胎，等待冷冻胚胎移植的适当时间。胚胎移植实际上是一个小手术，可以在10分钟内完成。

5、第五个环节:抽血验孕

一般来说，胚胎只有在进入子宫腔后3~4天才能植入，但胚胎植入时间受个体差异的影响，部分患者胚胎植入较晚。因此，为了提高妊娠检查的准确性，医生通常建议患者在移植后14天去医院进行血液检查。如果怀孕成功，B超声检查仍需在14天后进行，以排除异位妊娠。

 

**三、高龄卵试管婴儿费用**

无卵试管和常规试管的区别在于第三方**的问题，即促排对象不同，其他流程差别不大。目前国内老年女性无卵试管婴儿的费用在15-18万元之间。费用主要包括以下几个方面:

1、检查费用：并非所有不孕夫妇都能进行**试管婴儿。只有满足无卵适应症，才能进行。因此，有必要对这对夫妇进行全面的检查。检查费用一般在几千到一万元左右。

2、无卵费：无卵费，即具体的无卵**费，多受无卵者学历、外貌、基因等方面的影响。

3、试管费用：药物促排卵、促排、胚胎培养、胚胎移植、胚胎冷冻等费用包括在内。其中，促排卵药物的品种和剂量的差异会影响药物的成本。无卵年龄越大，剂量越大，成本越高。

**四、高龄无卵试管注意事项**

虽然老年**可以使用第三方**，以避免卵子老化、卵子畸形率高等问题，但孕妇可能面临身体状况不佳、子宫状况不佳等情况。因此，老年**、身体调节尤为重要，患者应特别注意以下事项。

1、注意身体的检查。准父母通常在做卵试管婴儿之前必须做全面的体检，这样医生才能了解准父母的身体状况。如果发现准父母有严重疾病，不能直接卵试管婴儿，必须先治疗。因为有些疾病对怀孕非常不利，如心脏病、糖尿病、高血压等，如果不先治疗疾病，突然提**试管受精，对胎儿和母亲非常不利，甚至威胁孕妇的生命。此外，如果准妈妈患有妇科疾病或宫腔疾病，她们必须在准备胚胎移植之前进行治疗，为胎儿和婴儿提供一个“宜居环境”。

2、补充叶酸。很多有生育经历的人都知道，医生要求准妈妈在孕期准备期间补充叶酸，一般要提前三个月补充。因为一般女性服用叶酸需要4周时间，体内的叶酸才能保持在更好的水平。如果叶酸本身缺乏的患者需要补充4~8周，叶酸缺乏的状态才能得到纠正，12~14周后才能保持稳定。因此，孕妇应提前补充，以便在妊娠早期（胎儿神经管敏感期）为胎儿提供叶酸，以满足神经系统发育的需要。卵试管婴儿也是如此，都需要为胎儿提供足够的叶酸。必要时，准爸爸也应该一起补充。

3、加强体育锻炼。现在很多人喜欢呆在家里，很少出去锻炼。从长远来看，这对身体健康非常不利，尤其是老年妇女，需要良好的身体来支持，以提高试管受精的成功率。适当的运动不仅能提高身体免疫力，还能增强心肺功能，对胚胎植入、胎儿发育、产妇分娩和产后身体恢复具有积极意义。因此，尽管准妈妈通常不喜欢运动，甚至讨厌运动，但她们也应该克服惰性，努力工作。

 

**以上是老年妇女在做**试管之前必须知道的事情。虽然老年**可以借助第三方**，避免卵子老化、卵子畸形率高等问题，但孕妇可能面临身体状况不佳、子宫状况不佳等情况。因此，老年**，身体调节尤为重要，只有良好的身体调节才能提高体外受精的成功率。**
